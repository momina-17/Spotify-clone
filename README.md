# Spotify Clone

A Spotify-inspired music player built using **HTML, CSS, and JavaScript**. This project recreates a simple music streaming interface with interactive playback controls and a collection of songs.

## Features

- Spotify-inspired user interface
- Play and pause songs
- Next and previous track controls
- Shuffle functionality
- Repeat functionality
- Interactive music progress bar
- Song selection from music cards
- Dynamic song title and album cover updates
- Fixed music player footer

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure the audio and image files are in their correct folders.
4. Open `index.html` in your browser.
5. Select a song and enjoy the player!
